# Public workflow comparison

The public Binary Ninja guide describes workflows for opening binary views, browsing code and data in address order, navigating blocks and cross-references, and moving between intermediate languages. Hexaris tracks its own implementation of those workflows in the [feature matrix](FEATURE_MATRIX.md). [User guide](https://docs.binary.ninja/guide/) · [Public API repository](https://github.com/Vector35/binaryninja-api)

Hexaris's source fixtures and comparison tools live under `tests/fixtures`. Use independently compiled test artifacts for reproducible comparisons. Keep local installation observations and evidence in the ignored research directory.
