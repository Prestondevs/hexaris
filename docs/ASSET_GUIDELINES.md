# Assets

The Hexaris mark uses a hexagonal outline and a split trace forming an H. The Graphite default uses dark gray surfaces, a cool accent, and amber for analysis warnings. Slate, Ash Light, Foundry and High Contrast use the same semantic color roles with different palettes. The toolbar theme menu previews those colors and shows hex codes on hover. The application rasterizes its local SVG assets at runtime and tints toolbar icons to match the current theme.

Tabler was selected for consistent 24-unit outline geometry and a verified MIT license for the bundled release. Lucide and Phosphor were reviewed as alternative outline families. Use the Tabler family for general controls and original vectors for Hexaris-specific marks. Record source, exact version, rights, changes and application use in the [asset manifest](../assets/ASSET_MANIFEST.toml).
